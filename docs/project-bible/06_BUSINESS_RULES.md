## Business Rules
Inventory = Opening + Receipts + Production In − Dispatch − Production Consumption − Stock-outs − Returns ± Adjustments. Available = Current − active reservations. FIFO uses physical dates. Shortage=Billed−Received; Accepted+Rejected/Damaged=Received. Recipe scaling = required output / expected recipe output. Actual production is authoritative. Payments are separate and allocated; unallocated amounts remain advances. History is corrected, not deleted.
