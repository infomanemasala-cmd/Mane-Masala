## Inventory and FIFO
Inventory is transaction-derived. Equation: Opening + Receipts + Production In − Dispatch − Production Consumption − Stock-outs − Returns ± Adjustments = Current. Available=Current−Reservations. FIFO uses physical receipt/production dates. Stock-outs and negative adjustments consume FIFO; positive adjustments create movement/batch. F-02/F-07/F-08 history protects date/conversion/idempotency semantics.
