## Returns and Adjustments
Supplier returns link to original purchase/line and reduce stock. Customer return flow is Receive→Inspect→Approve→Stock/Financial Adjustment; approved saleable quantity alone can return to stock. Stock adjustments are auditable inventory transactions; positive adds, negative consumes FIFO. Corrections preserve original history. Customer return schema exists but no dedicated public return-writer RPC was found, so this area needs reconciliation.
