## Glossary
Item=permanent material/product identity. Raw Material=ingredient. Intermediate=prepared real stock. Base Unit=controlled inventory unit. Reservation=commitment, not physical stock. Available=Current−Reservations. Receipt=physical receiving. Accepted=usable quantity. Shortage=Billed−Received. Production Batch=execution unit. Production Requirement=demand-linked need. Dispatch=physical stock movement. Sale=downstream sale. Invoice=billing document. Advance=unallocated payment. Allocation=payment-to-document link. Sub-Agent=billing party. Order Session=one entry session containing multiple permanent orders. Archive=history-preserving lifecycle state.
